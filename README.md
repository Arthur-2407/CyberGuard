#### Mathematical Objective Formulation
The network optimizes a joint loss function combining binary cross-entropy with a speaker identity cosine divergence penalty:

$$\mathcal{L}_{\text{total}} = \alpha \cdot \mathcal{L}_{\text{BCE}}(y, \hat{y}) + \beta \cdot (1 - \cos(\mathbf{e}_{\text{live}}, \mathbf{e}_{\text{ref}}))$$

Where:
- $\hat{y} \in [0, 1]$ represents the synthetic voice probability output by the Gated Fusion layer.
- $\mathbf{e}_{\text{live}}$ is the 192-dimensional ECAPA-TDNN embedding of the incoming acoustic chunk.
- $\mathbf{e}_{\text{ref}}$ is the verified biometric reference embedding enrolled in the caller's tenant database.
- $\alpha = 0.70$ and $\beta = 0.30$ dynamically balance synthetic detection with identity deviation.

## ◈ ZERO-TRUST PRIVACY & CRYPTOGRAPHIC DATA SOVEREIGNTY

CyberGuard enforces uncompromising enterprise security and data isolation standards:

- **Ephemeral Media Processing Directive**: Media analysis operates on in-memory streams or strictly scoped temporary scratch buffers protected by guaranteed cleanup handlers (`finally:` blocks). Raw voice, video, and image assets are never committed to permanent storage or databases.
- **Dynamic Policy Containment**: Three operational containment modes protect against false positives:
  - `OBSERVE`: Logs all findings and security telemetry without applying automated containment.
  - `ASSISTED`: Generates reversible containment proposals and remediation playbooks for human SOC analyst approval.
  - `ENFORCE`: Autonomously applies calibrated temporary/permanent blocks for confirmed high-confidence attacks.
- **Multi-Tenant Tenant Isolation**: Each user account is bound to an isolated SQLite tenant database (`data/user_databases/user_{id}.db`). Incidents, analysis records, and biometrics belonging to User A are physically isolated from User B.
